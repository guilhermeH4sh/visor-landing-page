# VISOR Landing Page

Landing editorial da marca **VISOR** (óculos premium).

## Stack

- HTML estático de alta fidelidade
- Tailwind CSS v4 (embutido)
- Tipografia: Playfair Display + Hanken Grotesk
- Imagens em `assets/template/`

## Estrutura

```
├── index.html
├── assets/template/
├── DESIGN.md
└── template-manifest.json
```

## Como visualizar

```powershell
start index.html
```
